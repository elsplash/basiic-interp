# BASIIC CShell

## About BASIIC CShell

This shell implementation is a simple program that uses the library
I have created just for this, though it is not the last time I will
use this library.

This is just a simple wrapper around the library, and also supports
file interpreting.

## Usage of BASIIC CShell

For compiling follow the main READMe in the repository root.

For usage of the shell program, you may follow the qBasic guide.

The flags are displayed by the flag `--help`, which you may use.
